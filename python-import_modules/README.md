# python-import_modules

## Description
This project covers Python modules: importing functions and variables
between files, using `sys.argv` to read command-line arguments, and
inspecting a compiled `.pyc` module with `dir()`.

| File | Description |
| --- | --- |
| `add_0.py` | Module defining an `add(a, b)` function |
| `0-add.py` | Imports `add` from `add_0` and prints `1 + 2 = 3` |
| `calculator_1.py` | Module defining `add`, `sub`, `mul`, `div` functions |
| `1-calculation.py` | Imports the calculator functions and prints results for `10` and `5` |
| `2-args.py` | Prints the number and list of arguments passed to the script |
| `3-infinite_add.py` | Prints the sum of all arguments passed to the script |
| `4-hidden_discovery.py` | Prints the public names defined in `hidden_4.pyc`, alphabetically |
| `variable_load_5.py` | Module defining a variable `a = 98` |
| `5-variable_load.py` | Imports `a` from `variable_load_5` and prints it |

## Requirements
- All scripts run on Ubuntu 20.04 LTS with python3 (3.8.5)
- All code follows pycodestyle (2.7.*)
- Every file starts with `#!/usr/bin/python3`
- Every file ends with a new line and is executable
- No file's code executes when imported (guarded by `if __name__ == "__main__":`)

## Note on task 4
`hidden_4.pyc` is not generated by this script. Download it into this
directory before running `4-hidden_discovery.py`:

```
curl -Lso "hidden_4.pyc" "https://github.com/alx-tools/0x02.py/raw/master/hidden_4.pyc"
```

It must be run with Python 3.8.x, since the `.pyc` was compiled with that
version and will not load under a different Python version.
