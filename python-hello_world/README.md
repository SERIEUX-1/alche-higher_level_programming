This project is an introduction to Python scripting. It covers the basics of
writing and running Python scripts and Shell scripts, including reading
input from environment variables, using f-strings, string slicing and
concatenation, and following the Zen of Python / pycodestyle style
guidelines.
 
Each task in this directory is a small, self-contained script:
 
| File | Description |
| --- | --- |
| `0-run` | Shell script that runs a Python script whose filename is stored in `$PYFILE` |
| `1-run_inline` | Shell script that runs Python code stored in `$PYCODE` |
| `2-print.py` | Prints a fixed string followed by a new line |
| `3-print_number.py` | Prints an integer followed by text, using an f-string |
| `4-print_float.py` | Prints a float with 2 digits of precision, using an f-string |
| `5-print_string.py` | Prints a string 3 times, then its first 9 characters |
| `6-concat.py` | Concatenates two strings into a new sentence |
| `7-edges.py` | Extracts the first 3 letters, last 2 letters, and middle of a word |
| `8-concat_edges.py` | Builds a new sentence from slices of existing strings, without new variables or string literals |
| `9-easter_egg.py` | Prints "The Zen of Python" |
